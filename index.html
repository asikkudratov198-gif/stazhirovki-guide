📄 Как составить резюме без опыта?

1. Образование

Вуз, факультет, курс. Укажите релевантные предметы: алгоритмы, базы данных, веб-разработка.

2. Пет-проекты (самое важное!)

Сделали учебный проект в вузе? Это уже опыт. Напишите на GitHub 2–3 небольших проекта: калькулятор, TODO-лист, Telegram-бот.

3. Навыки

  • Языки: Python, JavaScript, SQL
  • Инструменты: Git, Docker, Linux
  • НЕ пишите «уверенный пользователь ПК» — это не работает

4. Достижения

Олимпиады, хакатоны, волонтерство. Если ничего нет — укажите онлайн-курсы (Stepik, Coursera).

💼 Как пройти техническое собеседование?

Этап 1: Подготовка (за 1–2 недели)

  • Повторите основы: структуры данных, алгоритмы, ООП
  • Решите 20–30 задач на LeetCode (уровень Easy)
  • Подготовьте рассказ о себе на 2 минуты

Этап 2: Типовые вопросы

  • «Расскажите о себе» — не пересказывайте резюме
  • «Почему наша компания?» — покажите, что изучили их продукты
  • «Слабые стороны?» — говорите о реальных вещах с планом улучшения

Этап 3: Техническая часть

Не молчите! Говорите вслух, как думаете. Если не знаете ответа — скажите: «Я не уверен, но думаю, что...»
